## Getting Started

To start using the content in this repository:

1. **Clone the repository:**
    ```bash
    git clone https://github.com/ritik-gupta001/PyTorch.git
    cd PyTorch
    ```

2. **Set up a Python environment:**
    - Python 3.8 or newer is recommended.
    - It’s best to use a virtual environment (e.g., `venv` or `conda`).

3. **Install dependencies:**  
    If there is a `requirements.txt` file, install dependencies with:
    ```bash
    pip install -r requirements.txt
    ```
    Otherwise, install at least:
    ```bash
    pip install torch torchvision torchaudio notebook
    ```

4. **Launch Jupyter Notebook:**
    ```bash
    jupyter notebook
    ```
    Open your browser to the provided URL and explore the notebooks.
